# Architecture and threat model

`project.json` → optional explicit local Kokoro ONNX Hindi G2P + three distinct preset voice generation (no model download), or externally imported/online-consented original PCM → 45 validated original PCM WAVs + three PNGs → immutable source SHA manifest → exact-frame PCM chunks (1–10s) → FFmpeg/Pillow real 720p original static video + SRT.

Optional real neural stage: local explicit-rights/consent CPU SadTalker → one signed MP4+JSON per chunk → independent MP4 full decode/SHA → atomic checkpoint → local human pilot observations → full 45-turn candidate composer from original source WAVs and saved neural VIDEO ONLY → independent AAC/video/SRT audit → local 45-turn human review.

Dashboard is `127.0.0.1` only and rejects external origins and CSRF. It never serves `.png`, `.wav`, `.mp4`, `.json` workspace assets over HTTP. It never runs a model or posts media. HTML review is loaded locally by the owner.

Risks: external model licenses/weights, human likeness rights, private file security on user's PC, long CPU inference, manual lip-sync quality, non-cryptographic self-attested rights, old source-schema incompatibility. Source hashes detect accidental/modification changes but do not legally establish rights. A computer with no GPU may not produce satisfying results in practical time.
V3.3: The optional real CPU model stage first runs a read-only installed-model preflight before acquiring a session lock. Each face MP4's video stream must cover original PCM time, not merely its AAC audio. The compositor assigns frames using cumulative 24fps rounding across all 45 original dialogue turns and pauses to bound aggregate video drift. The saved original audio always supplies the final AAC stream. All structural checks remain separate from human visual/rights approval.

V3.4 subprocess boundary: `run-cpu` invokes the user-installed SadTalker via a separate, explicitly consented CPU-only Python process. The **upstream** official CLI accepts `--cpu`, `--still`, `--preprocess full` and writes a timestamp-named result MP4 under `--result_dir` (see https://github.com/OpenTalker/SadTalker/blob/main/inference.py). The app verifies one single private model MP4 and its original-WAV/portrait bindings before recording a checkpoint. On nonzero exit/timeout it leaves original stdout/stderr in the corresponding private `scratch/model-...` directory rather than streaming internal filenames into GitHub or buffering unlimited output in app memory. The test-only external simulator can check this process/FFmpeg handshake, but cannot verify real pretrained model compatibility or natural mouth motion. Offline Kokoro stages transient PCM in the private scratch volume as well.

V3.5 optional online TTS boundary: `tts-one` requires explicit `--allow-network-tts`; the selected original Hindi script text leaves the device. Network synthesis may not be repeated against an immutable signed source, and both existing voice WAVs and online-origin SHA receipts are protected by exclusive creation. Intermediate audio is converted in private workspace scratch. A project hash is compared again after the network await before adopting a 16k PCM file. This still is not voice quality or copyright certification.

V3.6 read-only local readiness report uses existing independent source SHA/PCM/media validators to guide the owner through the earliest safe next stage (import, bind, chunk, static, model/pilot, manual review, remaining previews, candidate composition). It never treats file presence as structurally verified video, and any failed SHA, corrupt audio/video, stale review or incomplete output creates a BLOCKED stage. It launches no model or network request, creates no file and cannot approve natural lip sync or publication.
