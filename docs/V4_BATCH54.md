# Batch 54 — resumable mixed video and studio exports

Explicit local actions and CLI commands: `project-mixed-video-resume --project-id ID` and `project-mixed-studio-resume --project-id ID`. These require the same already audited base video and current listening PASS as ordinary mixed composition. Existing compose stays scratch-only. Resume partitions each nonempty intro/speech/outro scene into consecutive chunks of at most 1,500 frames (60 seconds at 25 fps). Normalizes FPS and SAR, pads as in ordinary export, then trims by exact frame index and resets timestamps. Each chunk is frame-count checked before caching; restored copies must pass the existing SHA-256 and decoded frame verification. Cache namespace separates mixed variants from neural studio and binds the exact mixed seal, chunk plan and renderer identity. Shared inventory and explicit namespace deletion from Batch 53 cover these entries. Cooperative stopping retains verified chunks; final chronological concat, original mixed WAV, subtitle offsets, input revalidation, immutable final receipt and human review gates remain. No estimated time or persistent performance claim.

Tradeoffs: normalized frame-index trimming decodes preceding frames again for later chunks, potentially increasing CPU work on long episodes. Different encode boundaries may yield slightly different lossy pixels; raw-frame comparison only validates the filter selection. A chunk can still exceed the 256 MiB cache limit; use ordinary compose if it does. Cache storage persists until explicitly removed. Full export performance, actual models, hardware, and long-episode acceptance are unverified. No new dependencies.
