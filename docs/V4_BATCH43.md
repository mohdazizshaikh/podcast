# Batch 43 — combined measured loudness and peak correction

Supersedes the separate-mode limitation documented in Batch 42. Explicitly enable `--true-peak-guard --auto-peak-correction --target-lufs -16` with the normal mix acknowledgment. Browser accepts the same combination. Existing modes and receipt formats remain unchanged when not combined.

The new bounded_static_gain_retry_v2 normalization recipe first calculates the legacy bounded LUFS gain using baseline measurements and the stricter sample ceiling. Up to three measured attenuation retries use relative half-decibel steps (approximately 12 dB maximum retry attenuation relative to the initial gain), converted to one absolute integer gain from the same guarded baseline. No repeated quantization, no gain increase on retry, and no automatic claim of reaching LUFS target. Final measured true peak must be at or below -1.5 dBTP. Reports final measured target attainment within 0.5 LU; peak safety takes priority. Replays exact PCM, validates baseline digest and gain trajectory, remeasures final full loudness values at audit; intermediate measurements are receipt declarations. Bounded scratch disk includes up to four trial WAVs and final copy. Standalone correction and legacy normalization continue to use their earlier recipes. No new dependencies.
