# Batch 51 — mixed export progress and cooperative stopping

Extends the existing in-memory RenderProgress state machine with mixed stage labels and opt-out ETA, preserving defaults and prior event schema. Validates nonnegative integer intro/outro counts, positive speech count and exact total; omits zero-duration scenes. Mixed-video and mixed-studio compose APIs accept optional progress and should_stop callbacks. The dashboard's existing mixed-studio action forwards both, and its CSRF/task-ID-bound stop endpoint allows requests before the commit boundary. Existing saved candidates are audited without overwrite. Stop checks before input preparation, before and after verified scenes, after mux/decode verification, and at the final commit boundary after input revalidation; final save/audit cannot be interrupted by that stop control. TemporaryDirectory cleans precommit scratch work. Long speech re-encoding and input audit are not interruptible while the individual operation is running. No persistent resume or performance history. Mixed scenes are heterogeneous and at most three; ETA is intentionally unavailable, rather than estimating total time from intro-card speed. Original audio, shifted subtitles, existing receipts, listening PASS and human video review gates are unchanged.
