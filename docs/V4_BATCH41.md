# Batch 41 — conservative dynamic peak guard and measured acceptance gate

Optional whole-mix PCM guard after the existing sample limiter and before optional static loudness gain. Three frames of history/lookahead (7 samples total), instantaneous local gain cap, 800-frame (50 ms) linear release, maximum 22000 PCM, preserves exact sample count and polarity. Processes all roles and remains invariant to input block boundaries. No new dependencies. Original master untouched, no automatic listening approval.

`project-mix-compose --project-id ID --true-peak-guard --acknowledgment I_HAVE_RIGHTS_TO_ALL_ADDED_AUDIO_AND_AUTHORIZE_LOCAL_MIX`. Browser checkbox is off by default. Can combine with the existing sample limiter and LUFS normalization; bounded gain uses the lower sample ceiling. The final staged WAV must have finite measured FFmpeg true peak at or below -1.5 dBTP before the immutable mix directory is created. The receipt records measurement and recipe; audit repeats measurement and requires matching rounded value (changing FFmpeg versions can require revalidation). Missing or excessive measurements reject the candidate. Existing receipt formats are preserved when disabled.

The guard is NOT a standards-certified oversampled true-peak limiter: the conservative PCM cap and cubic interpolation test are not guarantees about sinc/FFmpeg reconstruction. Initial synthetic tests at 4000/6000/7500 Hz exceeded -1.5 dBTP (-1.15, -0.25 and +1.98 respectively) despite capped samples. The tests now require correct measured acceptance/rejection, not false claims of guaranteed success. Automatic adaptive oversampled correction, real listening, Windows and full episode acceptance remain pending.

71 authored tests: 40 length/pattern and conservative cubic bounds, 6 invalid settings, 7 invalid measurements, 3 valid measurements, 1 chunk/bypass, 1 lookahead/release, 6 actual FFmpeg synthetic tone tests, 3 project/dashboard combinations, 2 reject-before-save, 1 remeasurement and 1 CLI/browser case. 64 standalone tests passed in the local isolated harness (0.92 seconds). Seven integration cases not run; full repo checkout/CI unavailable. Batch 40 coefficient values independently checked against intended biquad formulas.
