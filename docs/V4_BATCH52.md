# Batch 52 — verified resumable neural studio segments

Opt in using the dashboard local action "Compose or resume neural studio (retain private verified cache)" or `python -m podcast_gpt --workspace PATH project-neural-studio-resume --project-id ID`. Use the same action after a cooperative stop. Existing compose remains scratch-only. Cache lives in the private project under studio-render-cache/<SHA-256 namespace>; never a final candidate. Namespace binds approved export inputs/settings, exact frame plan, relevant renderer source hashes, FFmpeg/ffprobe version output, Pillow, Python and OS identity. Each verified segment is copied into a staging directory and published with a receipt by same-filesystem rename; file and receipt flushed before publication. On resume the exact metadata, size and SHA-256 must match and a new scratch copy must pass hash and decoded frame-count checks. Matched pause segments bind both rendered neighbor hashes; absent entries rerender, damaged entries fail closed, not silently overwritten. Segment limit 256 MiB; larger segments require ordinary compose. Resume uses a more conservative disk estimate and disables provisional ETA because restored frames are not representative of encoding speed. Existing project lock, input revalidation, final frame check, immutable receipt and human review remain mandatory.

Cache is retained even after success. It contains private video and can accumulate across renderer/input revisions. Once all production processes are stopped and final media is verified, the user may manually delete only the studio-render-cache directory inside that private project to reclaim space, or use ordinary compose to bypass the cache. No automatic pruning/deletion, no authentication against a malicious local writer who alters both video and receipt, no guarantee of power-loss durability of directory rename, no recovery of an unverified in-flight segment. Process crashes may leave the existing project lock and scratch directory; follow existing stopped-process lock recovery before resuming. No mixed-video resume yet. No new dependencies.
