# Batch 58 — encoded transition correctness and real synthetic compositor regression

## Reproduced defect and fix

Real FFmpeg integration exposed a problem not covered by raw-video endpoint tests. In three matched-endpoint configurations, a planned 13-frame pause produced 13 encoded H.264 packets but ffprobe decoded only 12 frames; the final packet had a discard flag, MP4 duration was 0.48 s instead of the planned 0.52 s. The compositor correctly rejected the segment. The original endpoint hold graph used setpts but lacked explicit fps normalization of the looped decoded endpoint streams. Adding fps=25 after setpts in the shared hold chain produces the correct decoded frame count and 0.52 s duration in the reproduced case. No speech overlap, timeline modification, or change to approval gates. This does not create moving facial reactions.
