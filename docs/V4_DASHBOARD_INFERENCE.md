# V4 local dashboard inference, research packs and live task status

Use the existing private localhost dashboard, select the current project ID, choose one installed local engine and a 1–5 action limit. Tick the local model trust/usage-rights checkbox and the general authoring consent checkbox. Ollama generates an outline or one script unit per action using offline-only mode and approved under-3B tags; Kokoro/eSpeak each generate one eligible turn; SadTalker renders one eligible clip per action. The runner stays in the selected engine's permitted stages and stops at human review, missing inputs, incompatible engines, or the action limit. No cloud AI, API key loading for offline provider calls, automatic pulls, downloads or approval recording. All original model/asset validations apply. Trusted third-party executables may have their own behavior and are not sandboxed; prepare resources independently and use a trusted offline environment. Real inference remains unverified.

The local task display reports running/complete/blocked, command, measured elapsed seconds and, for the bounded runner, current action and verified completed action count. The count is relative to the selected action limit, not episode completion or an internal model percentage. Existing historical ETA remains separate. No process cancellation, background queue, persistent live progress or guaranteed ETA. Closing the application may interrupt work; inspect private checkpoints and recovery before retrying.

## Research packs
Enter an optional public query, authorize the internet request and authoring, and discover English Wikipedia candidate links. Copy suitable distinct HTTPS URLs to the list and separately authorize capture of 2–4 sources. The existing public HTTPS retrieval and immutable research pack limits apply. Inspect the saved pack through the dashboard. Neither discovery nor capture verifies factual truth or independent corroboration. Cloud AI credentials and recorded human approvals remain CLI-only.
