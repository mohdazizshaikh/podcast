# Batch 48 — pause-only speaker handoff crossfades

Optional studio transition selector: cut (legacy default), quick (up to six frames, 0.24 s at 25 fps), gentle (up to twelve frames, 0.48 s). CLI: `project-studio-configure --project-id ID --layout spotlight --transition gentle`. Dashboard including authorized background uploads supports the same mode. Existing requests and receipts remain unchanged when cut is selected. Studio settings remain immutable.

A handoff is scheduled only in an existing pause of at least three frames, bounded by outgoing speech from the same speaker/turn and incoming speech from a different speaker. The final bounded portion of the pause blends outgoing and incoming still portrait cards from fully outgoing to fully incoming. Earlier pause frames remain held. No new timeline frames, no overlapping neural clips, no audio change, no subtitle shift. Same-speaker handoffs, no pause, short pauses and terminal pauses use the existing cut behavior. Active facial clip and listener motion graphs are not modified. Frame count checks continue per segment and episode. The optional settings binding and scheduled pause handoff count are audited; actual visual approval still requires watching the video. Mixed studio inherits the audited base; static previews remain static.
